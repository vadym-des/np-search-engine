# Skill: Adaptive Model & Task Router

## Матриця вибору моделей:

### 1. Швидкий рівень — РУТИНА ТА ШВИДКОДІЯ
- **Моделі**: `Gemini 3.8 Flash`, `Gemini 4 Neon`.
- **Коли використовувати**:
  * Дрібні правки CSS, верстка HTML карток відділень, стилізація.
  * Додавання простих фільтрів у UI (наприклад, чекбокс поштоматів).
  * Запуск наявних автотестів, запуск локального вебсервера.
  * Точкові правки документації чи описів.
  * Пошук по файлах проєкту через grep/sed.

### 2. Експертний рівень — СКЛАДНИЙ КОДИНГ ТА АЛГОРИТМИ
- **Моделі**: `Claude Sonnet 5.5`, `Gemini 4 Argon`.
- **Коли використовувати**:
  * Логіка пошукового рушія (`app.js`, нечіткий пошук, валідація тезок, дезамбігуація).
  * Оптимізація пам'яті клієнта (JS Heap, утилізація сміття, layout thrashing).
  * Архітектурні зміни парсера поштових баз чи структури індексів.
  * Складні баги, що призводять до збою автотестів топоніміки.

### 3. Архітектурний рівень — ГЛОБАЛЬНЕ ПРОЕКТУВАННЯ
- **Моделі**: `Claude Opus 5.5`, `Orchestrator Gemini 4 Neon`.
- **Коли використовувати**:
  * Повний аудит безпеки та рефакторинг ядра системи.
  * Проектування нових масштабних модулів або міграція баз даних.

## Правило для агента:
Якщо поточна модель у чаті — швидка (наприклад, Gemini 3.8 Flash), а завдання вимагає глибокого алгоритмічного аналізу:
1. Запустити субагента відповідного рівня або виконати глибоку самоперевірку згідно `SEARCH_ENGINE_SPEC.md`.
2. За необхідності попередити користувача: *«Для максимальної точності цієї складної задачі рекомендую обрати Claude Sonnet 5.5 у меню моделей»*.
